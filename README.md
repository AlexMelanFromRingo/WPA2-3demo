# Методичка Wi-Fi: WPA2 · WPA3 · Hashcat 22000

Интерактивная визуальная методичка по безопасности Wi-Fi для **абсолютных
новичков**. Пошагово, с подсказками и схемами потоков данных показывает, как
устроены рукопожатие WPA2, обмен WPA3 SAE и математика офлайн-атаки режима
Hashcat 22000.

**🔗 Демо:** <https://alexmelanfromringo.github.io/WPA2-3demo/>

## Модули

1. **WPA2 4-Way Handshake** — пошаговая анимация: `PMK = PBKDF2(пароль, SSID,
   4096)` → обмен ANonce/SNonce → сборка PTK → создание MIC.
2. **WPA3 SAE (Dragonfly)** — как пароль превращается в точку эллиптической
   кривой P-256 (PWE) и почему перехват не даёт подобрать пароль офлайн.
3. **Симулятор Hashcat 22000** — переключатель атаки PMKID / EAPOL и пошаговая
   анимация перебора мини-словаря с красным/зелёным индикатором.

Общее: кнопки «Шаг вперёд/назад», авто-проигрывание, инспекция промежуточных
hex-дампов, все параметры редактируемы.

## Как это устроено

- **Криптография настоящая.** WPA2 (PMK/PTK/MIC) сверена с эталонным вектором
  IEEE 802.11i; WPA3 SAE считается на реальной кривой P-256 (hash-to-curve
  сверен с официальными векторами RFC 9380), корректность доказана сходимостью
  сторон.
- **UI не блокируется.** Все тяжёлые вычисления (PBKDF2 на 4096 итераций,
  EC-арифметика) выполняются в **Web Worker**; ввод проходит `debounceTime`.

## Технологии

Angular 21 (zoneless, signals) · Tailwind CSS v4 · TypeScript · WebCrypto API ·
[`@noble/curves`](https://github.com/paulmillr/noble-curves) (P-256).

## Запуск локально

```bash
npm ci          # установка строго по package-lock.json
npm start       # дев-сервер: http://localhost:4200
npm test        # юнит-тесты криптокорректности (20 тестов)
npm run build   # прод-сборка в dist/
```

Требуется Node.js 24 LTS и npm ≥ 11.10.

## Безопасность цепочки поставок

Репозиторий защищён от продолжающейся кампании атак на npm (Shai-Hulud).
Файл `.npmrc` включает:

- `ignore-scripts=true` — блокирует автозапуск вредоноса через lifecycle-скрипты;
- `min-release-age=7` — «карантин»: не ставить пакеты моложе 7 дней;
- точные (pinned) версии зависимостей + закоммиченный `package-lock.json`.

## ⚠️ Образовательная оговорка

Модуль 3 (Hashcat 22000) — **строго образовательная симуляция** математики
офлайн-атаки. Никакого реального захвата трафика и сетевого взаимодействия:
все вычисления идут только над данными, которые пользователь ввёл сам.
