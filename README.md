# Методичка Wi-Fi: WPA2 · WPA3 · Hashcat 22000

Интерактивная визуальная методичка по безопасности Wi-Fi для **абсолютных
новичков**. Пошагово, с подсказками и схемами потоков данных показывает, как
устроены рукопожатие WPA2, обмен WPA3 SAE и математика офлайн-атаки режима
Hashcat 22000.

**🔗 Демо:** <https://alexmelanfromringo.github.io/WPA2-3demo/>

## Разделы

0. **Справочник WPA2/WPA3** — подробное руководство: история от WEP до WPA3,
   участники и RSNE, иерархия ключей, жизненный цикл подключения, 4-Way
   Handshake сообщение за сообщением, строение кадра EAPOL-Key, шифрование
   CCMP/GCMP, Enterprise, SAE (H&P и H2E), PMF, сравнение версий, сильные и
   слабые стороны, каталог атак и практические рекомендации.
1. **WPA2 4-Way Handshake** — 11 шагов от пароля до установки ключей:
   `PMK = PBKDF2(пароль, SSID, 4096)` → M1 (ANonce, PMKID) → блок B →
   PTK = PRF-384 → KCK/KEK/TK → M2 (RSNE, MIC) → проверка точкой доступа →
   M3 (GTK под AES Key Wrap) → проверка клиентом → M4. Каждый кадр разобран
   по полям и байтам.
2. **WPA3 SAE (Dragonfly)** — 13 шагов: вывод PWE двумя способами стандарта
   (Hash-to-Element и Hunting-and-Pecking, переключатель), Commit, проверка
   чужого Commit, общий секрет k, KCK/PMK/PMKID, Confirm, затем 4-Way для AKM
   SAE (KDF-SHA-256, AES-128-CMAC, IGTK для PMF) и разбор, почему офлайн-перебор
   невозможен.
3. **Симулятор Hashcat 22000** — переключатель атаки PMKID / EAPOL и пошаговая
   анимация перебора мини-словаря с красным/зелёным индикатором.

Общее: кнопки «Шаг вперёд/назад», авто-проигрывание, инспекция промежуточных
hex-дампов, все параметры редактируемы (включая GTK и IGTK).

## Как это устроено

- **Криптография по стандарту.** Реализация следует IEEE 802.11-2020 (§12.4 SAE,
  §12.7 ключи и 4-Way Handshake) и проверена официальными векторами:
  IEEE 802.11-2020 Annex J.10 (SAE: Commit, KCK, PMK, PMKID, H2E PWE),
  IEEE 802.11i Annex H (PBKDF2, PRF), RFC 4493 (AES-CMAC), RFC 3394 (AES Key
  Wrap), RFC 5869 (HKDF) и настоящей строкой Hashcat 22000 с реальным кадром M2.
- **UI не блокируется.** Все тяжёлые вычисления (PBKDF2 на 4096 итераций,
  EC-арифметика) выполняются в **Web Worker**; ввод проходит `debounceTime`.

## Python-скрипты

В [`python/`](python/) лежат два учебных скрипта на чистом stdlib —
`wpa2_handshake.py` и `wpa3_sae.py`: их удобно запускать и править, чтобы
вспомнить работу протоколов. Чем они проще стандарта — см.

## Технологии

Angular 21 (zoneless, signals) · Tailwind CSS v4 · TypeScript · WebCrypto API ·
[`@noble/curves`](https://github.com/paulmillr/noble-curves) (P-256).

## Запуск локально

```bash
npm ci          # установка строго по package-lock.json
npm start       # дев-сервер: http://localhost:4200
npm test        # юнит-тесты криптокорректности по эталонным векторам
npm run build   # прод-сборка в dist/
```

Требуется Node.js 24 LTS и npm ≥ 11.10.

## Безопасность цепочки поставок

Репозиторий защищён от продолжающейся кампании атак на npm (Shai-Hulud).
Файл `.npmrc` включает:

- `ignore-scripts=true` — блокирует автозапуск вредоноса через lifecycle-скрипты;
- `min-release-age=7` — «карантин»: не ставить пакеты моложе 7 дней;
- точные (pinned) версии зависимостей + закоммиченный `package-lock.json`.

## ⚠️ Образовательная оговорка

Модуль 3 (Hashcat 22000) — **строго образовательная симуляция** математики
офлайн-атаки. Никакого реального захвата трафика и сетевого взаимодействия:
все вычисления идут только над данными, которые пользователь ввёл сам.
